GOAL
Implement a robust intake pipeline for documents/images that extracts financial fields (dates, amounts, vendor, line items), verifies them with a second pass, validates with sanity checks, stores immutable AnalysisRuns in Appwrite, and exposes a dev-only test route to exercise the pipeline on fixtures.

HARD RULES
1) Strict JSON only from AI calls. No markdown. Enforce schema validation server-side.
2) Never write finalized_* fields automatically. Only set suggested fields + needs_user_review until user approval.
3) Every run is immutable: create a new analysis_runs record for each run.
4) Add idempotency so the same file+prompt_version+model_version doesn’t create duplicate runs.
5) Use server-side Appwrite SDK with API key from Replit Secrets only (never expose to client).
6) Multi-page PDFs supported. OCR only when needed (scanned PDF detection).
7) Currency normalized as ISO + numeric. Dates normalized as YYYY-MM-DD.
8) If confidence < 0.85 OR validation fails OR image quality poor -> needs_user_review=true.
