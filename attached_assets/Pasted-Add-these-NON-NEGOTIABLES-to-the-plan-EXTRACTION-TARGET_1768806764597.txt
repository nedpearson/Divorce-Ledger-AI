VALIDATION GATE (must run before writing “finalized” fields)
- If confidence < 0.85 OR any required field missing for the detected doc_type → set needs_user_review=true and do NOT finalize.
- Money sanity checks:
  - If line_items exist, sum(line_total) must be within tolerance of subtotal/total when available.
  - Taxes/tips/shipping must not exceed total.
- Date sanity checks:
  - statement_period_start <= statement_period_end
  - transaction_date must fall within statement period for statements when both exist.
- Currency normalization:
  - Store ISO currency + numeric value (float/decimal). Never store “$1,234.56” as a string.
