==================================================
5. PRIORITIZED FIXING STRATEGY
==================================================

Fix issues in this order:

1) Hard crashes and build failures:
   - Anything preventing `npm run build` or the dev server from starting.
   - Any uncaught exceptions thrown in critical flows.

2) Infinite loops and runaway rendering:
   - React “Too many re-renders” errors.
   - Route guards that bounce between routes.
   - Effects that refire endlessly.

3) Data-flow and API errors:
   - Incorrect Appwrite calls,
   - Incorrect /api route parameter handling,
   - Mis-typed responses that cause runtime crashes,
   - Unhandled promise rejections and missing `await`s in:
     - evidence/document upload,
     - transaction ingestion,
     - incident logging,
     - report/export generation.

4) Critical UI/UX breakage:
   - Components failing to render because of errors.
   - Key flows (upload/delete/save) that silently fail (especially documents and violations).

5) Obviously dead or dangerous code:
   - Old, obviously wrong functions that are never called.
   - Commented-out hacks that should be replaced or removed.
