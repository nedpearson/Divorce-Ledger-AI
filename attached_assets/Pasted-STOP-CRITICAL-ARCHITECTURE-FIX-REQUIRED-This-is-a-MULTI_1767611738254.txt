3) API CALL PATTERN (enforce per-user isolation)
Every QB API call MUST:
- Get current authenticated user_id from session
- Fetch THAT user's qb_access_token from database
- Use THAT token for the API call
- If token expired, auto-refresh using THAT user's qb_refresh_token
- NEVER use another user's tokens

Example middleware:
```javascript
async function getUserQBClient(req) {
  const userId = req.user.id; // from your auth middleware
  const user = await db.query('SELECT qb_access_token, qb_refresh_token, qb_realm_id FROM users WHERE id = $1', [userId]);
  
  if (!user.qb_access_token) {
    throw new Error('QuickBooks not connected. Please connect in Settings.');
  }
  
  // Check if token expired, refresh if needed
  if (isTokenExpired(user)) {
    await refreshQBToken(userId);
    return getUserQBClient(req); // retry with fresh token
  }
  
  return createQBClient(user.qb_access_token, user.qb_realm_id);
}
```
